# Fluxos de Trabalho do RADAR PUB

## MVP Vertical Flow

1. **Discovery** - descobre leads via fontes (fixtures no MVP)
2. **Research** - coleta presença digital e sinais
3. **Analysis** - detecta problemas com base em sinais
4. **Scoring** - calcula score por dimensão e score geral
5. **Opportunity** - gera hipótese, motivo, próxima ação

## Future Loops

### Discovery Loop
- Fontes: scraping, APIs, feeds, referrals
- Freq: contínua (24/7)

### Research Loop
- Fontes: browser automation, SEO tools, social APIs
- Freq: contínua

### Qualification Loop
- Freq: contínua
- Entrada: Research + Score
- Saída: Opportunity

### Outreach Loop
- Freq: contínua
- Entrada: Opportunity qualificado
- Saída: lead preparado para contato

### Follow-up Loop
- Freq: contínua
- Entrada: lead contactado
- Saída: lead atualizado com resultado

### Learning Loop
- Freq: contínua
- Entrada: feedback comercial, conversão
- Saída: modelos atualizados, decisões aprendidas
